Tujuan

Dokumen ini mengunci operasi maintenance yang tidak termasuk filesystem cache deletion biasa.

Kategori:

```
filesystem cleanup
block-device maintenance
filesystem maintenance
memory/compression maintenance

Android platform operations
```

Prinsip utama:

```

TRIM
F2FS maintenance
ZRAM operation
sysfs/procfs mutation
```

tidak boleh memiliki jalur eksekusi langsung dari:

```
CLI
IPC
Scheduler
Policy
```

Semua harus melewati:

```

    │
    ▼

    │
    ▼

    │
    ▼

1. Maintenance Bukan Cleanup Generic

Maintenance operation adalah operation dengan:

```

```

```

4. Typed Operation
