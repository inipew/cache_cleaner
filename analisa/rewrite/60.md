Tujuan

Verifier adalah komponen read-only yang menentukan apakah hasil operasi benar-benar mencapai postcondition yang diharapkan.

Executor menjawab:

```
"Apa hasil mutation attempt?"
```

Verifier menjawab:

```
"Apakah filesystem/platform sekarang
 berada pada state yang diharapkan?"
```

Alur:

```
AuthorizedOperation
      │
      ▼
Executor
      │
      ▼
OperationResult
      │
      ▼
Verifier
      │
      ▼
VerificationResult
      │
      ▼
Aggregator
      │
      ▼
JobResult
```

1. Verifier tidak melakukan mutation.

2. Verifier tidak boleh memanggil:

   unlinkat
   rename
   mkdir
   chmod
   ioctl

atau mutation primitive lainnya.

3. Verifier hanya melakukan:

   read
   stat
   fstatat
   open read-only
   metadata inspection

sesuai filesystem abstraction.

4. Verifier tidak boleh:

   memperbaiki hasil

5. Jika postcondition gagal:

   report

bukan:

```
mutate again
```
