51.md — Durable Storage Architecture, JobStore, OperationStore, Transaction Boundary, Journal vs Snapshot, Atomic Persistence, Schema Versioning, Migration, Corruption Detection, Retention, and Persistence Security Contract

Tujuan

Dokumen ini mengunci storage layer yang menjadi fondasi durability pada 50.md.

Storage layer bukan sekadar tempat menyimpan data.

Storage layer harus menjamin bahwa:

```
lifecycle job
operation progress
recovery evidence
final result
audit metadata
```

dapat dipertahankan secara konsisten ketika terjadi:

```
crash
power loss
process kill
disk full
partial write
corruption
upgrade
migration
```

Arsitektur:

```
Domain
  │
  ▼
Persistence Interfaces
  │
  ├─────────────────────┐
  ▼                     ▼
JobStore            OperationStore
  │                     │
  └──────────┬──────────┘
             ▼
      Durable Storage
             │
    ┌────────┼────────┐
    ▼        ▼        ▼
  Journal  Snapshot  Metadata
    │        │        │
    └────────┼────────┘
             ▼
         Recovery
             │
             ▼
```
