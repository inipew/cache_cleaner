Lanjut. Sekarang masuk ke **`platform/`**, dan ini salah satu layer paling penting karena seluruh logika Android-specific harus berhenti di sini.

Prinsip utamanya:

Semua itu diterjemahkan menjadi primitive yang dimengerti domain.

# 677. Rule paling penting untuk `platform/`

Saya akan jadikan ini invariant:

```text id="q5m8r2"
1. Platform reports facts; it does not authorize deletion.
2. No arbitrary path resolution from IPC/config.
3. Android UserId != Linux UID.
4. CE/DE are explicit storage domains.
5. One unlocked user does not imply another user is unlocked.
6. Unknown storage state is conservative.
7. Package names are validated types.
8. Package identity is not inferred solely from path when high assurance is required.
9. API level is not a substitute for capability detection.
10. Properties are not security authority.
11. SELinux denials are never fixed automatically.
12. Protected targets never enter cleanup catalog.
13. Target selection is not authorization.
14. Platform snapshots are not permanent truth.
15. Fast-changing state must be revalidated.
16. Domain never contains Android paths.
17. Platform never performs destructive filesystem operations.
18. Platform discovery failure never falls back to arbitrary filesystem traversal.
```

```text
 ↓
RelativePath
 ↓
TrustedRoot
 ↓
DirectoryHandle
 ↓
openat / fstatat
 ↓
identity + type validation
 ↓
unlinkat
```

Kita juga perlu membedah secara konkret **TOCTOU**, `openat2`, `O_NOFOLLOW`, `AT_SYMLINK_NOFOLLOW`, `RESOLVE_BENEATH`, `RESOLVE_NO_XDEV`, `getdents64/fdopendir`, ownership `OwnedFd`, dan bagaimana membuat delete tetap fail-closed ketika file berubah tepat di antara scan dan unlink.
