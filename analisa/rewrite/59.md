Dokumen ini mengunci implementasi Executor.

271. Secure Single-operation Algorithm

Conceptual algorithm:

```
1. Receive AuthorizedPlan.
2. Validate plan identity.
3. Validate fingerprint.
4. Validate authorization expiration.
5. Validate generations.
6. Select next Pending operation.
7. Verify operation belongs to plan.
8. Verify dependencies.
9. Check cancellation.
10. Check execution budget.
11. Acquire resource lock.
12. Check cancellation again.
13. Open TrustedRoot.
14. Validate root identity.
15. Resolve parent FD.
16. Validate mount boundary.
17. Revalidate target identity.
18. Revalidate object type.
19. Run final safety gate.
20. Check expiration again if required.
21. Persist durable intent.
22. Check mutation budget.
23. Perform exactly one authorized mutation.
24. Capture syscall outcome.
25. Persist outcome.
26. Close FDs.
27. Release locks.
28. Send result to Verifier.
29. Continue only if lifecycle permits.
```
