Tujuan

Resource Manager adalah lapisan yang mengatur:

```
berapa banyak pekerjaan yang boleh berjalan
resource apa yang sedang digunakan
resource apa yang harus dikunci
kapan pekerjaan harus ditunda
bagaimana mencegah contention
bagaimana mencegah starvation
bagaimana memastikan resource dilepas
```

Resource Manager bukan:

```
Authorization
Policy
Safety
Executor
Scheduler
```

Alur:

```
Scheduler
   │
   ▼
ResourceManager
   │
   ├── Budget
   ├── Reservation
   ├── Lock
   ├── Pressure
   └── Fairness
   │
   ▼
Worker
   │
   ▼
Executor
```
