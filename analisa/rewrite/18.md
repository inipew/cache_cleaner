Lanjut. Sekarang kita mulai mengunci **`domain/` secara konkret**. Ini adalah fondasi rewrite; setelah bagian ini stabil, layer lain tinggal mengimplementasikan kontraknya.

# 119. Prinsip `domain/`

`domain/` harus menjadi layer paling "bersih":

```text
domain/
    ↓
tidak tahu Linux
tidak tahu Android
tidak tahu libc
tidak tahu filesystem syscall
tidak tahu UDS
tidak tahu epoll
tidak tahu config file
```

Bahkan kalau nanti kita menjalankan unit test di laptop biasa, seluruh domain harus tetap bisa di-test.

Dependency ideal:

```text
domain
  ├── std
  └── dependency kecil untuk error/serialization jika benar-benar perlu
```

Jangan biarkan `domain` bergantung ke:

```text
fs
platform
kernel
runtime
executor

```
